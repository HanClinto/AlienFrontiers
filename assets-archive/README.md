# Alien Frontiers - Archived Assets

This directory contains all the original assets from the iOS version of Alien Frontiers, preserved for use in future implementations.

## Archive Date
November 5, 2025

## Contents

### Images (461 files)
- All PNG sprite sheets and UI elements
- Icon files for various resolutions (iPad, iPhone, etc.)
- Game board graphics
- Player pieces (ships, colonies, dice)
- Facility and location graphics
- Tech card graphics
- UI buttons and frames
- Font files (TTF, FNT)
- Sprite sheet definitions (PLIST, ZSS)
- Vector graphics source files (AI)

### Audio (34 files)
- Sound effects (CAF format)
- Music tracks (MP3 format)
- UI interaction sounds
- Game event sounds (dice rolling, ship placement, etc.)

### Rules and Documentation (7 files)
- Official Alien Frontiers rules PDFs (multiple versions)
- Credits and attribution documents
- Development notes

## Original Source
All assets were extracted from the iOS version located at:
`alien-frontiers-ios/AlienFrontiers/Resources/`

## Usage Notes
These assets are the foundation for rebuilding Alien Frontiers in any new framework. They include:
- Complete visual assets for the game board, pieces, and UI
- All audio feedback for game interactions
- Official game rules and documentation

## Next Steps
With these assets preserved, the repository can be cleaned and rebuilt from scratch using modern web technologies while maintaining visual and audio consistency with the original iOS version.
